# 🌐 Saylani Portal Website

A modern and responsive **Saylani Portal Website** designed using **HTML, CSS, JavaScript, and Bootstrap**.
This project is inspired by **Saylani Welfare International Trust** and showcases their services, programs, and information in a clean, user-friendly interface.

---

## 🚀 Features

✅ Responsive and mobile-friendly design
✅ Clean and modern UI
✅ Header with navigation bar
✅ Banner / Hero section
✅ Courses / Services section
✅ About section
✅ Contact section
✅ Footer with useful links
✅ Smooth scrolling and animations

---

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Bootstrap 5
* Font Awesome Icons

```

```

3. Run the project:
   Just open `index.html` in your browser.
